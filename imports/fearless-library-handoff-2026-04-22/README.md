# README — Fearless Library Root

This directory is the working root for publisher-organized library content on `reality.local`.

## What Is Here

- publisher directories such as `Archie Comics`, `Dark Horse Comics`, and `Rebellion`
- `FOUND_FILES/` for located-file notes or staging artifacts
- `MISSING_ISSUES.md` for issue-gap tracking
- handoff files for restarting Codex work in this directory

## Read First

1. `AGENTS.md`
2. `HANDOFF.md`
3. `MEMORY.md`
4. `MISSING_ISSUES.md`

## Working Style

- inspect the live tree first
- keep notes short and current
- log important decisions before making broad library changes
- avoid assuming older NFS or bind-mount notes are still accurate without verification

## Current Intent

This handoff set exists so a new Codex session can be started directly from `/mnt/fearless/LIBRARY` and continue library work without depending on the older Cirrus repo session.
